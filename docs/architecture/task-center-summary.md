## Owner、接线与授权

复用 Skill 之外现有 Task、Review、Agent Configuration 各自授权只读接口。新增 Next BFF `GET /api/workbench/task-center-summary`，serverAuth 验证会话，expected user/org 与现有 context/cookie 一致；context 返回的当前权限及服务部署状态决定读取哪些来源。BFF 通过既有请求构造、响应校验和代理调用，不访问数据库、不接受浏览器指定上游、来源权限或任意 URL，不增加事实 owner、schema 或状态机。每一页继续由原 owner 重新授权；结束再读取当前 context，身份/企业/权限变化时丢弃全部结果。响应 private/no-store。

Task/Review/运行的原有业务事实和写入流程不变；只允许固定 GET，不执行模型、恢复、审核、Apply、发布或账本操作。Figma 不作为视觉依据。

## 统计和关联

Task 以 task ID 唯一，Review 以 proposal ID 唯一，原生运行以 agent ID + run ID 唯一。Task 明确给出的 reviewId 去除相同 Review；workbench_scoped Review 不独立计数。Task 的 agentRunId 仅与其 kind 对应的正式 agent ID 精确关联并去除相同原生运行，不按商品、时间或名称猜测。文本 human_review_required 不作为额外待确认；具体待处理事实由 Task/Review 提供。异常与暂停分别归类，不重叠。UI 列表复用同一准确关联规则，保留原 owner 详情和锁。

## 资源、失败与刷新

每次统计有整体 12 秒 deadline，继承请求取消；固定来源分页、并发不超过 4、全局不超过 100 次读取和 5000 条记录。重复 cursor、错误、权限不明或达到上限返回明确 partial/unavailable，不能把不完整数据当总数；不生成默认零。已知但不属于五状态的记录用 excluded 数说明，不使其它已知状态全部不可用。来源关闭与来源读取失败区分。统计查询缓存 key 绑定身份、企业、授权和业务范围，切换或撤权不保留旧数；刷新沿现有显式刷新，业务动作完成使该统计失效。无模型调用及新持久化重试/恢复协议。

汇总为多次授权读取的当前观察，不宣称跨 owner 原子快照。出现关联冲突或同一身份记录不一致时保守返回不完整；无权限不得返回旧数据或错误缩小的精确总数。
