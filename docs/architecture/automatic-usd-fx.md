# 平台美元参考汇率自动更新候选

状态：**周更增量 IMPLEMENTATION_READY**。执行任务 [#1249](https://github.com/henryxu1008/shuomi-ai-commerce/issues/1249)。此前按日更新的实现已合并；2026-11-12 用户决定改为每周自动更新，以下周更决定取代本文其余部分与日更及公告日历相关的冲突条款。独立架构增量复核未发现阻断；定时相位和公告时点通过本节及实现测试收敛。

## 2026-11-12 用户决定：每周更新

用户要减少运维复杂度：系统每周自动获取一次 CFETS USD/CNY 中间价，已成功核验并发布的参考汇率使用一周；到期仍未更新时停止新的美元费用报价。用户接受周内参考汇率不随每天中间价变化；已冻结、已预留和已结算的请求继续使用原事实。本决定改变参考报价的时效，不改变模型价格、点数单位、账本、权限或真实实例操作授权。

复用原固定来源、原价格 owner 和唯一协调器，每 168 小时调度一次；不因下一公告工作日 09:15 将本周参考价提前失效，正常运行不再需要维护年度公告日历。若例行触发早于当前自动周价到期，协调器持久等待至到期再重新采集并核验，不提前截短这周，也不忽略信号后再多等一周；STOP 应能唤醒等待。触发时间与核验时间不同步时仍可能有短暂报价间隙。候选数据仍需有有效的 CFETS 公告日期和数值，拒绝未来日、日期倒退、同日不同值及明显过旧数据；若公告日期是上海当天，须在 09:15 或之后才能接受。以核验时上海自然日为准，公告日期不得早于该日之前七个自然日，以防第三方长期卡在旧值；此阈值不证明其为最新公告，管理页须分别展示公告日及使用有效期。遇长假或来源延迟导致取不到符合条件的新公告，允许旧参考价用到原有效期，之后停报；不能为了连续性延长原参考价。

成功发布时以服务端核验时刻作为生效起点，失效时刻为该时刻后 168 小时，区间左闭右开；这是平台估算使用期限，不是声称交易中心中间价一周不变。每周无新公告的重复读取不得刷新有效期或制造新版本；错误、超时、UNKNOWN、人工冲突及停用继续沿用现有安全边界。仅当原请求确定未提交且冲突处理符合原合同才允许重试；不得将旧原键与新有效期混用。每周计划触发失败不自动延长有效期，保留明确失败或未知状态，下一次例行触发或经现有安全规则处理后才可恢复。

本轮只变更自动汇率的频率、有效期及为周更必要的源日期验证，并在现有管理页说明公告日、核验/失效时间和周内为参考价。保留人工发布、原价目/其他币种、冻结引用、默认关闭和显式启用；不新增日历服务、告警平台或第二事实源。改成每周不解决数据使用授权；真实接线前仍须确认渠道对本项目的许可和费用。不得修改原实例、调用真实模型、合并或部署，除非另行授权。

验收以合成来源和隔离价格 owner 证明：一周中工作日与周末均可按同一冻结参考价报价、满 168 小时后新报价拒绝、正常下周新公告可更新、失败/旧日期/重复公告不延长有效期，其他货币和旧冻结事实不变。覆盖现有协调器冲突、原回执及默认关闭的受影响路径；不把模拟测试当成真实授权或现场验收。

下文为此前日更架构及其仍适用的不变量；凡要求每日刷新、下一公告日 09:15 过期或必须维护公告日历的内容，均被上述周更决定取代。

## 用户结果与范围

平台维护的美元模型参考价需要有效的人民币汇率，否则 Chat 等使用方无法报价。用户于 2026-11-12 同意平台统一自动更新：正常中间价变化无需逐次询问，仍须保持旧请求冻结、有效期保护和账本原语义。此决定在本任务范围取代[企业统一模型配置](enterprise-shared-model-configuration.md)中禁止自动抓取汇率的条款，不改变其他适用合同。

首期只处理 CFETS USD/CNY；不抓模型价、不新增货币配置平台、不访问模型或账单、不为每个企业维护汇率。实际接线、实例变更和真实模型调用另按用户授权执行。人工平台维护入口仍可使用；已确认的非美元记录、模型价和历史事实必须保留。

## 所有权与路径

`PlatformPricesService` 和现有 `ai_route_config` current/revision 是唯一价格事实 owner；本功能从固定官方来源取得一个候选，严格解析后读取当前快照，以原 `Publish` 的 expectedRevision、事务和回执发布修改后的完整快照，所有消费者继续使用原引用、校验与结算。不建立第二汇率表或旁路写库。新调度器默认关闭，采用仓库现有运行与调度能力；以下生命周期及注入方案须独立评审，不能通过构建启动时自动启用。

2026-11-12 独立增量复核通过的协调方式：单一固定 ID 的持久 coordinator 跨公告日串行处理。Temporal 固定 schedule 每小时启动轻量 tick；tick 只能向现有 coordinator 发 signal，绝不启动或重建它。协调器依次采集、校验并固化完整发布输入；结果 UNKNOWN 时只核对原回执，不处理其他日期的发布。无 coordinator、终止、不可访问或状态不明时为 UNKNOWN，不自动重建。重复 signal 不产生重复发布，signal 丢失仅等下一次采集；仅以 signal 成功不能声称价格已发布。

初始化为显式的隔离/部署操作：只允许全新安装下创建固定 ID 且 paused 的 schedule（持久初始化标志，不自动删除），再创建 coordinator，核实后才启动 schedule。已有 schedule、初始化 ACK 不明、coordinator 不可核对均禁止盲目重建；现有部署接线仍须单独授权。默认关闭时不读取来源、不启动 worker、不创建资源。关闭先暂停 schedule，排队信号及在途操作仍可能存在，不能把 pause 或单一实例退出视为全局停止完成。此协调仅保存编排与原命令，不改变原价格 owner。

2026-11-12 独立增量复核：全局停用以**不再自动写汇率**为结果，而不以所有共享 worker 退出为前提。先暂停 schedule，再向唯一 coordinator 发送持久 STOP；只在其确认没有可继续的原活动、所有原键结果已确认且进入持久 `QUIESCED`（后续普通 tick 永久拒绝发布）后，才能报告自动更新停用完成。等待期间可有先前在途提交，状态须为 DRAINING/UNKNOWN；单个实例停止、pause、signal ACK 或空回执均不证明停用完成。协调器不可达/终止或原事务结果不能确认时保持 UNKNOWN。共享 worker 仍可领取其他工作，人工价格发布不受此停用影响；不承诺自动恢复启用。该判据替代此前‘所有副本不得领取工作’的实现方式，保持不发生后续自动写入的用户结果，不新增协调事实 owner。须验证 STOP 与 tick/活动/续写并发和多 worker，不能证明时不得启用。

2026-11-12 用户决定：继续使用中国外汇交易中心 USD/CNY 中间价，允许通过其他接口获取，不转换为第三方混合参考汇率。获取渠道候选为 [Frankfurter](https://frankfurter.dev/) 的固定 provider 端点 `https://api.frankfurter.dev/v2/providers/cfets/rate/usd/cny`，不得使用默认混合报价或其他 provider。2026-11-12 只读观察为 `{"date":"2026-11-12","base":"USD","quote":"CNY","rate":6.7174}`；11 月 5、6、9、10、11、12 日与交易中心当日原始公告数值逐日相符。这是六日抽样而非持续准确性或服务承诺。

固定 HTTPS 主机及路径，不接受浏览器或配置传入任意 URL；设置超时、响应大小限制并拒绝异常重定向。必须严格校验日期、`base=USD`、`quote=CNY`、正的十进制数，精确乘 1,000,000 后成为整数；超过六位小数或溢出拒绝，不使用二进制浮点或四舍五入。日期不能为未来或早于当前已接受公告；HTTP 非 200、空响应、结构变化或无法判明币种时失败关闭。记录**实际获取渠道 Frankfurter、provider CFETS 和原始公告日期**；现有价格 `SourceURL` 表示原始公告来源而非声称直接从官方站点下载，实际渠道须有可持久核对的事实依据。必须验证这一来源表达符合当前合同，不能伪造来源。

该接口无需 API key、由第三方提供，可能延迟、缺失或更正；接口及原始数据条款分别适用，不能因开源或一次匹配就假定具有无限服务保障或官方授权。部署前核对适用条款及渠道稳定性；禁止以 Frankfurter 默认混合汇率、其他商业中间价或另一供应商静默兜底。

独立复核发现该第三方 [CFETS 适配器](https://github.com/lineofflight/frankfurter/blob/main/lib/provider/adapters/cfets.rb)使用浮点处理；本系统精确解析仅保证**接收到的数字**换算不引入额外误差，不能据此证明第三方转录全链逐位无误。固定 provider 仍可能晚到、缺失或修订；有效期结束后新价尚未可用时应停报，小时调度也可能增加等待。换渠道不会自动提供公告日历或保证不间断服务。

Temporal 已结束工作流历史按 namespace retention 清理，不能作为获取渠道永久唯一证据，也不能单凭拒绝重复 workflow ID 保证跨 retention 的永久去重。实现需优先验证现有不可变 revision 中固定可信 actor 能否区分采集渠道，加上官方 `SourceURL`、公告日、数值及持久 receipt 原键是否足以记录事实并核对重复；若不能，另设计原 owner 内最小来源字段，不默认新增归档或表。短期原始响应可保留在 Temporal 历史，但不能声称永久可查。该项为实现验证，若实际无法如实记录来源或安全去重，须停止并按具体后果重新分类。

## 版本、有效期及冲突

发布时保留全部模型价和其他币种；对 USD 合并新的不重叠时间段，不改写已冻结的引用。新公告的切换时刻为成功核验后服务端当前时间；在新 revision 中将覆盖该时刻的旧 USD 区间结束时间截短到切换时刻，再插入新 USD 区间。区间为左闭右开；切换时刻须晚于旧区间起点，且小于新公告按有效期计算的上界，否则停止。旧 revision 和已冻结请求的汇率、版本不修改。若已有未来生效的 USD 区间与候选重叠，不覆盖或截短未来预约，停止并通知维护者；同一日期不同价格视为更正候选，同样停下核对。

发布前将来源公告与当前已接受的最新 USD 公告比较：更旧日期一律不发布；相同日期和值为 no-op；相同日期但不同值停下核对。只有日期严格更新、且通过时效与来源校验的公告才可自动发布，CAS 冲突重新读取后必须再次比较，防止缓存或乱序使汇率倒退。

`FreezePlatformPrices` 当前限制快照最多 8 条 FX；不能每天无限追加。须确认历史请求从原 revision 或其冻结事实可恢复后，只在当前快照中裁剪已结束且不再影响当前解析的旧区间，历史 revision 和用量事实不修改；无法证明时停止发布并报告。新公告重复读取须幂等，不重复产生无意义版本。

发布输入从 current 快照复制所有价目和 FX 的原字段，但移除每条记录的 `Version`；现有 `FreezePlatformPrices` 对未变化项按内容保留原版本。不得将带版本的 current 直接提交，也不得重置未变化记录的其他字段。

周末或节假日若官方没有新公告，可继续使用最近公告，但不能在下一个公告工作日的发布窗口后沿用前一工作日价格。候选的失效时间为下一个已核验的中间价公告工作日上海时间 09:15；工作日及休市日须来自适用于该公告的官方日历，且覆盖相应日期，不能仅按周六周日猜测，遇调休也不猜测。日历不可证实时只给予至下一个自然日 09:15 的保守有效期，到期后停止报价。官方长假期间可在已核验休市日期内使用最近公告，恢复公告日到点仍未取到新价则停报。网络失败、响应异常或日期不可证实时不延长有效期，不清除既有记录；过期后沿原保护拒绝新报价。定时刷新与过期检查不改变已预留或已结算请求。

候选日历作为受限服务器配置，由平台维护者根据与中间价发布日直接相关的交易中心年度官方公告核验后提供，包含适用年份、来源和明确的开放/休市日期；不是另一份汇率账本，不自动下载未知年份或从其他市场日历推断。配置缺年、缺日、重叠或来源无法核验时走上述保守失效规则；到年末提前维护下一年，运行管理页应提示日历缺失。具体官方公告是否覆盖中间价发布日须在实际接线前核实，不能将拆借市场或外币对日历直接当成中间价日历。

普通周末依据：[交易中心 2026.3 数据信息服务简介](https://www.chinamoney.com.cn/dqs/cm-s-notice-query/fileDownLoad.do?contentId=1716546&mode=open&priority=0)称中间价于每个交易日 09:15 公布；[人民币外汇交易介绍](https://www.chinamoney.org.cn/chinese/mgwhcphjy/)称周六、周日及法定节假日不开市。由此按人民币外汇市场交易日推断普通周末及周末补班休市，不用普通办公补班日历替代；这是依据两项规则作出的推断，并非‘交易日公布’本身排除特殊非交易日公告。官方特别安排优先。跨长假仍须与人民币外汇市场适用的当年休市资料核验；其他市场的交易或结算日历不得冒充。年份未覆盖、临时安排未知或资料冲突时，在最早可能的下一公告时间停报，不将异常猜成休市。第三方新价延迟不延长旧价：工作日 09:15 起取不到当日值即暂停新报价，直到有效新价到达。

并发人工发布必须以当前版本 CAS：冲突时重新读取并合并新快照，不能覆盖人工价格或其他币种；若人工更新同一 USD 生效区间或来源无法判断则停止并报告。发布身份必须是受限、可审计的平台服务身份，人工权限不因而放宽。由于 `PlatformPricesService.Publish` 本身不校验权限，服务 actor、价格 writer 数据库连接和启用开关只能在可信服务端装配中注入；不得接受浏览器或普通请求传入 actor、writer 或调度参数，也不借用用户会话。接线默认关闭，现有其他业务账号和权限不变。

实现将自动尝试前的 USD 行固定在协调器历史中；确认版本冲突后仅当重新读取的 USD 行完全相同才合并其他币种及模型价格的修改。USD 行发生变化时进入持久 `USD_CONFLICT` 并拒绝后续自动 tick，维护页显示需要核对；该状态不会自动恢复，仍可请求安全停用。

隔离数据库实测发现事务可能等待 current 行锁至候选过期；候选增量是在原事务取锁后、写入前使用数据库时钟校验自动命令的截止时间，失败则回滚并区分结果不明，人工发布不改变。该检查不能证明 WAL 实际提交绝不会跨越时刻；因此消费者仍须使用原 `Resolve` 的有效期校验，提交回执只能称 PUBLISHED，不能据此宣称当前可报价。事务末尾发生长时间停顿或 ACK 丢失须隔离验证，未证明时不得启用。

协调器跨日期唯一；幂等键包含平台、币种、官方公告日。同一天不同公告值不创建第二个自动发布。每个发布尝试在调用前将精确 actor、原幂等键、expectedRevision 和包含 VerifiedAt、切换时间、所有价格及 FX 的完整原输入固定到持久历史，重启恢复必须使用原载荷与原键。成功、失败和未知按原回执对账；无回执且原调用可能仍在途时保持 UNKNOWN，不使用新键或新载荷。只有明确且确认未提交的 CAS conflict 才能在重新读取后以新尝试处理。协调器本身被终止、丢失或不可查询时保持 UNKNOWN，不由 schedule 自动重建。continue-as-new 仅允许无在途、无 UNKNOWN 且保留全部未处理信号的安全点；历史保留期不能代替原 owner 持久回执。

## 运行与验证

面向维护者至少显示最近公告日期、适用汇率、有效期及更新失败/过期状态，复用已有管理入口；状态不得声称实时或成功，系统不可用时显示未知。调度与观测只服务本功能，不建设通用告警系统。

接线以 `modelRoutePricing.automaticFX` 为显式开关，省略时不连接调度器、不运行更新 worker；启用配置只需指定本机 Temporal 地址和 namespace，不再维护年度公告日历。配置不自动创建 schedule 或发布价格；真实接线仍须确认渠道许可、费用和稳定性。

平台管理员可在现有「模型与费率 → 参考价格与汇率」查看已保存的美元公告和有效期及最近一次协调状态。首次初始化、请求停用和状态查询分别由平台管理 API `/api/v1/model-route-pricing/platform-prices/automatic-fx/start`、`/stop` 和 `/automatic-fx` 提供；写操作要求既有平台管理员及写权限，不接收调用方自定义来源、服务身份、调度参数或价格。初始化结果不明不得盲目重试；停用请求返回 UNKNOWN 属于正常的等待状态，只有随后查询为 `QUIESCED` 才表示不再自动发布。若 coordinator 不可查询或被终止，状态保持未知；本期不提供自动恢复启用。
