# 平台美元参考汇率自动更新候选

状态：**NOT_READY，待独立架构评审**。执行任务 [#1249](https://github.com/henryxu1008/shuomi-ai-commerce/issues/1249)。本文是设计候选，不表示代码、部署、现场发布或用户验收完成。

## 用户结果与范围

平台维护的美元模型参考价需要有效的人民币汇率，否则 Chat 等使用方无法报价。用户于 2026-11-12 同意平台统一自动更新：正常中间价变化无需逐次询问，仍须保持旧请求冻结、有效期保护和账本原语义。此决定在本任务范围取代[企业统一模型配置](enterprise-shared-model-configuration.md)中禁止自动抓取汇率的条款，不改变其他适用合同。

首期只处理 CFETS USD/CNY；不抓模型价、不新增货币配置平台、不访问模型或账单、不为每个企业维护汇率。实际接线、实例变更和真实模型调用另按用户授权执行。人工平台维护入口仍可使用；已确认的非美元记录、模型价和历史事实必须保留。

## 所有权与路径

`PlatformPricesService` 和现有 `ai_route_config` current/revision 是唯一价格事实 owner；本功能从固定官方来源取得一个候选，严格解析后读取当前快照，以原 `Publish` 的 expectedRevision、事务和回执发布修改后的完整快照，所有消费者继续使用原引用、校验与结算。不建立第二汇率表或旁路写库。新调度器默认关闭，采用仓库现有运行与调度能力；准确生命周期及注入方式须在独立评审中确定，不能通过构建启动时自动启用。

候选读入只允许固定 HTTPS 官方域与固定请求，不接受页面提供的 URL；设置请求超时、响应大小限制并拒绝异常重定向。必须校验响应成功、唯一 USD/CNY、公告日期、正值和精确十进制换算，禁止浮点近似、猜数、未来日期或以空响应冒充公告。源接口目前是现有页面使用的实际接口，公开稳定性和服务条款尚待核实；若无法确认可靠数据源，保持 NOT_READY，不以其他供应商替换。

## 版本、有效期及冲突

发布时保留全部模型价和其他币种；对 USD 合并新的不重叠时间段，不改写已冻结的引用。`FreezePlatformPrices` 当前限制快照最多 8 条 FX；不能每天无限追加。须确认历史请求从原 revision 或其冻结事实可恢复后，只在当前快照中裁剪已结束且不再影响当前解析的旧区间，历史 revision 和用量事实不修改；无法证明时停止发布并报告。新公告重复读取须幂等，不重复产生无意义版本；同一日期不同价格视为更正候选，不能静默覆盖，按明确协议停下供维护者核对。

周末或节假日若官方没有新公告，可继续使用最近公告，但不能无期限延长。候选最大公告年龄为 **72 小时**，从公告日期在上海时区起算；超过则停止生成新的有效汇率并展示过期状态。此保守候选可能使较长假期暂停报价，须评审确认适配现行产品决定。网络失败、响应异常或日期不可证实时不延长有效期，不清除既有记录；过期后沿原保护拒绝新报价。定时刷新与过期检查不改变已预留或已结算请求。

并发人工发布必须以当前版本 CAS：冲突时重新读取并合并新快照，不能覆盖人工价格或其他币种；若人工更新同一 USD 生效区间或来源无法判断则停止并报告。发布身份必须是受限、可审计的平台服务身份，人工权限不因而放宽。重复调度和多个副本须保证同一候选不会重复发布；提交结果未知时按原幂等键查询原回执，再对账，不能换键盲目重发。停止调度、进程重启或故障恢复仅重试符合上述条件的同一原操作。

## 运行与验证

面向维护者至少显示最近公告日期、适用汇率、有效期及更新失败/过期状态，复用已有管理入口；状态不得声称实时或成功，系统不可用时显示未知。调度与观测只服务本功能，不建设通用告警系统。

采用合成来源与隔离数据库验证：成功与无新公告、周末及长假、坏格式和异常来源、超时/不可用、过期、重复/并发与人工冲突、未知提交后的原键恢复、8 条限制、其他价格和其他币种保留、既有冻结请求与预留不变。还须验证关停后不会写入以及所有实例默认关闭。真实源只作只读访问，不调用模型；现场发布、部署和用户验收分别为 NOT_RUN。

## 评审待决

1. 官方数据源的稳定性与允许自动获取的依据，以及节假日长时间无公告的适用期限。
2. 使用现有调度能力的可重复执行、服务身份与启停边界；不能以人工权限或任意 URL 冒用平台 owner。
3. 历史汇率裁剪、精确冻结引用及未知结果恢复是否完整复用现有存储和回执。
4. 自动更新与人工 USD 发布冲突时的最终行为，以及有限界状态展示是否足以让维护者处理失败。
