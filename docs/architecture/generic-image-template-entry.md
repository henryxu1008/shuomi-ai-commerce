## 复用依据与 owner

引用 [完整图片](product-image-agent-v1.md)、[视觉 brief](image-skill-visual-brief-v2.md)、[准确技能商品入口](official-skill-product-entry.md) 和现有 agentconfig / `image-config-v1` 合同。

- 通用方案只是现有 `imageTemplateInputSchema` 的三份初始值，各一项标准任务：商品主图 `product_identity`、场景 `usage_scene`、详情 `key_benefits`。均不含商品名、型号、固定规格或来源 URL；背景/中文说明不增加事实或任务。
- 管理员在 ImageAgentPage 选择“从此方案新建”，再沿原保存/幂等/回执入口创建企业模板。选择方案和只读导航不写数据；不自动安装、不设置或清除默认、不覆盖任何模板。
- Skill 仍是方法唯一 owner；方案不创建/编辑 Skill，不替换入口准确 ID/version/digest。
- 配置 owner 保存可执行的企业模板与不可变版本。ImageSet 仍冻结准确模板、方法、来源、任务、报价；Asset 仍由明确人工批准保存。

## 本次计划选择规则

1. 有企业默认引用时，仍只读取该准确版本。读取失败、已归档或不适用时如实阻止；不以通用方案掩盖错误，不改默认任务和数量。
2. 无默认、没有旧 run/intent，且从已核实官方图片技能入口开始时，按对应通用方案发现已保存 ACTIVE/product 模板。必须完整比较 image 参数，不按模板名称判断；使用读回的真实 UUID/version。普通列表页仍按现有每页1条的响应大小合同读取，最多20页自动发现；未找到保留手动分页/选择和管理员保存提示。
3. 未进入技能入口、个人/团队方法、旧 run/未核实 intent 不自动推荐或换模板。用户手动改选后不被延迟发现覆盖。
4. 三种官方图片方法分别对应三种方案，但不会修改已选 Skill 或历史计划。任务和原图仍可明确选择；prepare/点数确认、provider、计费和批准重验均沿原 owner。

不新增持久化映射、表、API、授权、状态机、恢复/UNKNOWN 协议、provider 或规划调用。URL 仍只是绑定 actor/org 的导航提示。Legacy decision: N/A，不引入退休 owner、兼容层、双写或第二事实源。

## 验证与授权边界

TDD 覆盖三份通用方案合法且商品无关、准确版本/原图进入原 prepare、跨页匹配和失配拒绝、默认优先及读取失败不换选、旧请求字节保留、普通成员不可保存配置；相关既有恢复/UNKNOWN 回归、类型/lint、CI、明暗主题。

真实验证拟使用另一类公开商品的独立记录，每技能一张，先明确模型、单价、总调用/点数/人民币上限及失败即停规则，再获得对应授权。未执行前保留 NOT_RUN；不把测试、代码复核或预算提案当作用户验收。
