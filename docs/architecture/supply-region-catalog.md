# 账户资料与供应市场共用中国省市目录

执行 [#1322](https://github.com/henryxu1008/shuomi-ai-commerce/issues/1322)，依赖 [#1321](https://github.com/henryxu1008/shuomi-ai-commerce/pull/1321)。2026-11-16 用户已明确批准账户资料、供货申请及发货地筛选共用同一份中国省市清单。已有账户区县镇原样显示，主动修改才重选。已有商品须能按旧发货地查询；完成后在 35444 试用。

## Design Basis / Independent Architecture

- 现有只读地区目录仍由 internal/geography 负责。现有 Vant 2.2.0 数据生成的 34 个省级选项及 396 个城市选项是中国省市唯一有效来源。保留原顺序、名称、直辖市和省直管县层级。全球 GeoNames 快照用于国家索引和其他国家省市；其中国条目仅保留国家元数据。
- 组合目录在加载时将中国省市挂到现有 CN 条目，统一 Country(CN) 与 Resolve。目录版本由全球快照版本和中国省市生成物共同决定，仍用现有版本格式。现有地区读取端点的 country=CN 和已运行的 country=CN&view=shipping 均调用同一个查询并返回完全相同的响应。新账户和新供应 UI 都使用标准 country=CN 请求。原省市下拉、商品列表筛选和供货表单继续使用已定义的选择约束。
- Account Profile 继续持有账户地区文本。已保存区县镇原样读取和显示，复用无法匹配时提示重选的既有规则。普通资料读取和独立保存不自行清空或替换地区。只有显式提交当版有效父子 ID 才更新，既有明确清空动作仍可用；旧 ID 和旧版本不能写入。
- SupplyMarket 继续持有发货地。既有供货申请、商品记录、精确文本筛选、排序分页、身份、企业权限、恢复及冻结请求不变。无历史数据改写、新表、文本别名、外部调用、状态机或持久化协议变化。
- 35444 先切后端。既有供应 UI 可继续访问已运行的查询参数，旧账户页仍按原响应结构读取；切换前已打开且持有旧目录的账户保存被版本检查拦截，刷新后可重选。仅更新受影响镜像并保留实例配置和数据。

## 验收

使用目录和 HTTP 测试确认两条 CN 查询响应完全相同，验证省市父子、版本、旧账户值保留和新 ID 保存。前端确认旧区县镇提示可见且可按统一清单重选，供应端调用标准 CN 请求，原发货地过滤和值不变。核查运行入口及身份边界；供货申请由用户登录试用。

从仓库根目录执行 node web/listingkit-ui/scripts/generate-shipping-regions.mjs 可重建中国省市目录。源包 @vant/area-data 固定为 2.2.0，原许可及版权保存在 internal/geography/VANT-LICENSE。
