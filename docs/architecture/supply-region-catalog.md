# 供应市场发货地接入共享地区目录

执行 [#1322](https://github.com/henryxu1008/shuomi-ai-commerce/issues/1322)。2026-11-16 用户已在 35444 验收账户默认中国和地区联动，批准供货申请与发货地筛选接入，并更新 35444。依赖 [#1321](https://github.com/henryxu1008/shuomi-ai-commerce/pull/1321) 的已试用目录，开发 PR 基于其当前分支。供应市场现有发货地范围不扩大。

## Design Basis / Independent Architecture

- 用户操作：自营供货声明、优选公共发货地和逐件发货地选省市；自营、优选市场列表可只选省，也可加选城市。国家沿用现有固定范围。上级切换清下级，筛选清除沿用原按钮。
- Owner：`internal/geography` 负责只读参考目录，SupplyMarket 继续持有已提交的发货地和查询语义。账户视图使用 GeoNames 的当地名称及聚落层级；现有供应市场以「浙江省／杭州市」等规范短串对已发布记录精确匹配。将已固定使用的 Vant 2.2.0 数据投影纳入同一共享目录包，保留原省市名称、直辖市和省直管县规则。保留数据源及 MIT 署名。两视图各有用途，通过同一只读目录端点取得，不在浏览器保留第二份发货地字典。
- 调用：锁定 Vant 文件 → 生成共享目录的发货地视图 → 现有账户 region-catalog 读取 `?country=CN&view=shipping` → 同源 BFF → 供应市场共享查询与既有省市控件 → 原申请/列表接口。只允许 `CN` 及精确参数组合。响应沿现有 country catalog 结构和上限，带现有版本，GeoNames 响应和账户保存版本保持兼容。
- 选择只来自预置目录。新申请填写时，应用在现有表单阶段核对所选地名和归属，缺少可用目录不能提交该步。列表的其他筛选在目录读取失败时可继续用，错误可重试。应用把选择变成原规范名称，服务端命令和查询继续消费原字段。服务端供货声明写入和市场查询合同保持原样，此批没有改动已发送请求的校验或恢复路径。
- 保留既有身份校验、同源写、角色、企业隔离、精确筛选、排序、分页、审核、发布与按原请求恢复语义。目录读取无写入，禁止在目录载入时触发申请或筛选。无新表、迁移、历史数据改写、别名匹配、外部调用、第二业务事实或新状态机。
- 35444 切换先后端后前端：旧前端可继续用原省市表单，账户地区请求保持兼容；新前端找不到新视图时提示重试，供货申请不可凭空写入。保留此前账户试用改动及现有服务配置。回退先前端后后端。生产、合并和真实发货申请提交不在授权范围。

## 验收

检查新目录投影明确维持原标签和现有发货层级，覆盖浙江／杭州、直辖市、直管县及稀有选项；接口拒绝匿名和越界参数。回归自营及优选表单、继承与逐件覆盖、组合筛选和清除，目录失败时确认不阻塞其他筛选。明确区分受控测试和用户在 35444 的实际操作。

独立架构复核通过，状态 IMPLEMENTATION_READY。实现验证覆盖参数白名单、原省市名称及层级、列表局部失败和申请缺少有效目录时的提交保护。
