# 官方技能模板自动准备

状态：IMPLEMENTATION_READY；独立边界复核确认以下约束。执行范围承接 #1276 和用户 2026-11-14 的最新决定。

## 用户结果与范围

系统准备好技能库后，用户无需安装即可在技能库查看、使用已开放的官方模板。系统设置保留已有的官方模板管理；移除手动安装按钮。不改变个人和团队技能、模型、账本、商品或发布行为。

## 边界与现有能力

继续以 `skill_capability` 为唯一事实 owner，使用仓库内固定发布包、确定性技能 ID、现有版本存储、事务和 advisory lock，不引入第二份在线目录。公开读取、使用、复制及维护权限沿用 Skill V1。后台自动准备由可信应用启动路径执行，不从用户请求、角色声明或前端触发，不向 HTTP 暴露系统写权限。系统 creator 仅作来源标记，不伪造用户或平台管理员身份；不改变现有 creator。

## 事务与保留

本决定对原应用装配“仅验证、不写模板”合同作有界例外：在 Skill schema 验证通过并完成存储构造后，执行模板准备，不进行 DDL 或修改权限。仅对固定发布包中不存在对应 skill 的项目创建当前发布所需的完整版本链。已有对应 skill 的历史、状态、修订和头版本完全保留，不自动恢复或升级。相同 ID 归属不符或记录损坏视为冲突。与原手动维护使用同一事务锁；并发启动或重试不会多建。冲突或写入失败时事务回滚，不覆盖原记录。无 Skill schema 时继续沿用当前不可用行为。

准备失败应可由服务日志定位且不含模板正文，不能伪造已准备成功；保留已有技能读写和其他模块启动，包括只读连接。下次正常启动允许重试，不建立新调度或恢复系统。普通用户读路径仍只读；不调用模型、不访问外部平台。更新原实例时沿用当前对原预留的保护配置。
