# #132 标题先导的本机操作入口

Design Basis 为 **Independent Architecture**。状态为 **R2_CANDIDATE**。本设计扩展 [#132 标题对照准入](issue132-title-evaluation-admission.md) 中的运行装配。代码基线为合并后的 [#1106](https://github.com/henryxu1008/shuomi-ai-commerce/pull/1106)（`5eae13a3`）。评测目标、样本范围和指标来自 [#132](https://github.com/henryxu1008/shuomi-ai-commerce/issues/132)。用户已同意就隔离实例的只读预检和受控启动方案做独立架构评审，之后进行合成验证。

操作员在 #132 专用实例使用现有已验证的会话，查看单个获准批次的准入结果。取得本次付费授权后，由批准记录中指定的成员显式启动该批。两组各用相同的 30 份冻结样本，执行止于标题建议或人工审核前的停止状态。发布官方价目、调整点数、部署、真实模型调用和正式评测各有独立授权。本入口供操作员调用，无产品 UI 变更。Legacy decision 为 N/A。

## 装配与权限

- 复用 [当前应用的完整标题装配](../../cmd/current-application/main.go) 和 [Product Agent application](../../internal/app/httpapi/product_agent_application.go)。隔离候选必须配齐并检查同一隔离实例的 Product/SRC、Review、Asset、Run/Invocation、Commercial 及现有身份验证、共享路由和官方价目。现有 G298 content-only 和仅凭据配置继续用于各自用途。由受信任的隔离运行清单和实际专用库身份核对连接范围，确认该批只使用该清单中唯一的原 Run Store。任一依赖、库身份或已发布的标题路由缺失时拒绝装配，禁止改用其他实例。
- 默认装配没有 #132 入口。在专用装配中，由代码限定的本机入口选项注入 `titlePilotApproval`。现有 [仅合成传输的构造门禁](../../internal/app/httpapi/product_agent_application.go#L266) 保留为测试路径。新增真实装配分支必须同时得到受信任的隔离选项、匹配的完整标题依赖及批准记录。它消费当前已发布的企业共享标题路由、官方价目、凭据读取者和现有受治理传输。共享配置缺失时拒绝，沿原发布权限配置。空 `TextTransport` 只选用正常传输，启动资格仍由前述门禁判断。
- 独立操作监听器绑定 `127.0.0.1`，路由表只含预检与启动。主 API、Console BFF 和现有反向代理均没有指向这个监听器的路由。入口检查 TCP 对端和准确的 Host，拒绝 Forwarded 或 X-Forwarded-*，限制请求体。验证实际监听及代理拓扑。操作监听器与主进程共用原 DB 池和应用生命周期，启动失败或退出时一同关闭。对同机调用仍依赖下述会话和授权，不把回环地址当成用户身份。
- 两个操作都使用现有 verified bearer、产品 Review 请求能力绑定与实时组织权限链。要求来源写入、标题 Agent 使用权限及批准记录的企业／操作者／成员三者精确匹配。批准记录还绑定唯一批次 ID、冻结样本摘要、精确模型 profile digest、凭据 revision、价目和 FX 版本，以及原预算。正式启动需要在这些同一字段上另行确认有效起止时间和付费执行授权。请求既不接收替代身份，也不允许提交批次 ID、样本、模型、端点、费用或预算覆盖。启动是显式 POST。令牌仅在已有认证链中使用，回执和操作日志只留必要的版本、状态和请求标识。

## 预检和启动

1. **只读预检**核对认证、权限、实例和批准记录、当前连接与已发布费率及 FX 版本，并构造与正式启动共用的冻结计划元数据。验证内嵌样本摘要及 30 份来源命令，导出 60 个预期槽位和顺序。通过原 owner 的 `Verify` 和 Run Store 只读查来源及首槽回执。仅原 owner 明确返回未找到时标记待首次发布。已有回执须与冻结来源和操作者吻合，读取错误和冲突阻断。沿 Commercial 的 `ReadBalances` 与 `ReadMonthlyLimit` 读取精确企业可用余额和成员本月剩余额度，后者为月限扣除已用和预留。按整数微点计算预留上界，缺少有效的余额状态、账本单位或额度时拒绝启动。
2. **正式启动**重新执行同一组预检门禁，再进入 [现有批次执行](../../internal/app/httpapi/product_agent_title_pilot.go#L131)。现有 `prepareTitlePilot` 会通过 SRC/Catalog 发布样本，所以它只属于正式启动。已有的正确来源回执按原键复用。两组绑定同一真实发布版本。执行沿用固定组一次调用、Agent 组最多六次的更严限制，单任务最多 60 秒，沿现有发送前额度预留与结算。
3. 有期限授权必须覆盖每次样本写入、首次及后续 Claim、以及最终发送门禁。以上操作前重验授权期和冻结批准记录，逐次发送还重验当前路由、实时权限和额度。整个启动请求期限涵盖准备和 60 槽，取服务端固定绝对上界、授权截止、bearer 截止与调用方取消的最早值。独立监听器的请求及写回期限与这一运行期限相容。请求取消、超时和进程关闭向下传播，没有脱离请求继续的后台任务。已经发出的调用按既有结算与 UNKNOWN 规则处理。
4. 以现有首槽原键的首次 Claim 决定唯一执行者。并发的 SRC 写入在 Claim 之前也只复用相同来源命令和原键。已见首槽、无法读取、权限或版本漂移、会话过期、请求中断或费用为 UNKNOWN 时，停止推进并按原键查询，保留原预留和已有回执。首槽结果未明时禁止再次尝试。预检通过不预占额度，实际以正式启动重验及逐次预留为准。

## 计费与验证

两组只用 `gpt-5.4-mini-2026-03-17`、`openai-direct`、全球标准同步文本服务和已准入的完整计量。按 [模型官网](https://developers.openai.com/api/docs/models/gpt-5.4-mini) 与 [中国外汇交易中心](https://www.chinamoney.com.cn/chinese/bkccpr/) 2026-11-05 中间价 6.7156 做离线预览。16,384 输入 token 与 2,048 输出 token 下的保守人民币报价为每次 ¥0.144413，210 次为 ¥30.326730。对应点数预留上界 3,032.657670 点。两组任务配额仍受原每调用 ¥0.18、全批 ¥38 上限及更小的现行限额约束。实际启动只接受仍适用的已发布版本，且企业余额和成员剩余额度都要覆盖上界。离线报价只作评审输入。

合成验证复用 [已合并的 owner 集成测试](../../internal/app/httpapi/issue132_title_pilot_integration_test.go)，用任务专属临时 PostgreSQL 与进程内传输。新增覆盖默认无入口、依赖不全拒绝装配、代理和身份拒绝、预检零样本／Run／Invocation／预留／结算写入和零发送、只允许明确 NotFound、点数或费率不足拒绝、预检后漂移及过期拒绝。用假钟验证会话或付费授权在样本、Claim 和最后发送前到期的结果，并覆盖请求取消、并发原键去重。已有组合测试继续覆盖 30 份发布回执、60 个槽位、逐次门禁和 UNKNOWN 停批。正式评测与付费先导状态为 `NOT_RUN`。
