# Chat 语音输入与会话入口

状态：独立架构评审通过，**IMPLEMENTATION_READY**。按实施测试验证单次识别 generation 和独立身份字段、晚到事件、光标与最新手输、超长及存储失败、权限与设备错误，以及合成替身不调用真实识别。

## 用户结果与范围

内容型 Chat 新建页提供带无障碍名称的箭头按钮，明确表示开始对话；它仍调用原创建流程，需求进入会话后保持未发送。用户点击麦克风后，浏览器提供语音识别，识别文字插入当前可编辑草稿，不自动创建、发送、规划或调用应用 AI 模型。项目及店铺背景、权限、8192 字节限制、存储失败与原键重试沿用 `chat-compose-before-create.md`。

## Owner 与外部边界

语音只属于当前页面的临时输入，不新增服务端事实、表、会话、账本、凭据、媒体资产或后台任务。复用浏览器 Web Speech API，须向用户明确：浏览器可能将语音发送给其服务商处理；由浏览器负责麦克风授权与识别。应用不接收、保存或上传音频；不得静默切换其他供应商或把此功能声称为本地识别。真实识别仅由用户之后主动操作；本次验证以受控合成识别事件进行，不发送音频或调用模型。

## 输入与生命周期

只有用户点击后开始识别，支持停止，浏览器不支持、权限拒绝、无设备、无识别结果和服务错误均应给出可理解的提示并保留当前文字。以浏览器最终识别结果为准，按结果索引去重；在当前光标处插入，不替换用户输入；草稿继续经现有写入和校验。避免异步识别覆盖用户在录音期间输入的文字。正常停止等待当前识别的最后结果和结束事件；卸载、身份或入口上下文变化、创建请求开始或草稿不可编辑时中止识别并忽略旧事件，不允许跨用户或跨店铺写入。识别长度超限沿现有创建校验处理。语音不可用不影响键盘输入；输入焦点及可访问状态可用。

## 权限、副作用与验证

浏览器权限和服务商传输须在开启前可见，禁止自动申请麦克风。识别过程外部结果失败或中断只影响未提交的识别片段，保留已确认文本，不自动重试。会话创建的认证、租户隔离、幂等、恢复及发送边界均不变；不改变计费、资源或模型准入。使用受控 SpeechRecognition 测试双击、最终结果去重、已有文本和光标、用户中途编辑、拒绝／错误／停止、身份与上下文切换、卸载和无自动发送；桌面及窄屏明暗主题检查。合成浏览器拦截所有 API 并断言零消息和零语音外部请求；不以合成识别声称真实麦克风验收。用户授权后仅更新原 35444 前端，保留数据、配置、原预留和回退入口。
