# #1070 首试验收清单与离线走查

使用者是有当前企业项目和资料权限的跨境选品人员。首试从 **Amazon 美国站关键词或类目 → 确认一个市场机会 → 匹配 1688 货源 → 核对 SKU 与采购数量 → 参考试算 → 人工批准并转入一件商品准备**。验收结论也可以是「证据不足」或「暂不推进」。固定 ASIN 继续用于回读与比较的回归验证。

本轮是 [#1070](https://github.com/henryxu1008/shuomi-ai-commerce/issues/1070) 的文档走查，`Design Basis: N/A`。所有资料、报价、汇率、回执和业务身份均为合成样例，编号是阅读用别名。没有真实采购、采集、模型或付费调用。本页定义预期行为与现场核对项，真实验收为 `NOT_RUN`。

## 首试验收清单

| 步骤 | 操作与通过条件 | 验收时留存 |
| --- | --- | --- |
| 1. 提出调研目标 | 打开本人「产品研究」项目，选 Amazon 美国站，输入关键词或选择一个有效类目。走现有 Data Services 查询与字段/范围确认。关键词模式不预填 ASIN；类目模式使用站点的 `categoryNode`。离线替换为下文查询对应的静态结果。 | 站点、查询模式、实际词或类目、上限和实际返回数。 |
| 2. 形成机会 | 从本次查询取得的样本中读回原版，核对币种、价格口径与已观察规格。形成一条机会说明，含使用场景、建议规格、样本价格、证据引用和未知项。切换词后按新结果判断，旧样本保留在原记录中。资料不足时显示具体缺项，不能把旧结论带入。 | 查询范围、采集时间、所用商品及原发布 ID / 版本、解析版本与原校验标识、结论及限制。 |
| 3. 人工确认方向 | 卖家确认机会和商品要求，再进入同一项目的智能选品。本例使用一个现有 Amazon 候选作为下游评审锚点，附上确认的要求及支持证据。确认机会和最后「批准测试」是两次不同决定。 | 确认人、方向、版本化证据、要匹配的要求及代表候选。 |
| 4. 找货和核对 | 按确认的功能、尺寸、包装要求筛货，首试由卖家从已收藏且能回读服务端发布的 1688 条目人工匹配。精确选来源 SKU 和采购数量（正整数件），记录规格差异和理由。货源发布换版、撤权或 SKU 无法确认时，依原合同停在重新核对。 | 1688 条目及原发布 ID / 版本、来源 SKU、数量、单位、规格比较、核对回执。 |
| 5. 参考试算 | 确认假设售价、指定 SKU 与数量适用的采购价、币种、费用、汇率及出处/日期。完整时显示参考贡献利润和保本价；只有起价、错 SKU、错档、过期或缺出处时，采购价留空并列待询项，完整利润和保本价留空。试算独立于人工决定。 | 输入与来源、已知费用、缺项、计算结果。当前试算在页内使用，验收记录留存输入输出，不把它记为已存系统历史。 |
| 6. 人工只批准一件并转入 | 只对 A 提交「批准测试」与理由，B 留在待研究。到「转入我的供应链 → 核对 1 件商品 → 我的数据」复核原批次非空子集 `[A]`，再确认转入。用商品准备原回执读回恰好一个条目，来源仍是批准时的 Amazon 原版。1688 SKU 留在 A 的 Research 货源核对记录中。 | A 的人工决定回执、只含 A 的转入请求及原回执、商品准备读回的发布 ID / 版本和数量 1。响应未知时按原请求键查回执。 |

## 离线样例

### 静态输入

查询均为 `site=us`，离线最多取 5 条详情。5 是样例上限。每行代表可独立回读的一份合成 Data Services 原版。A、B 同属一个收藏批次，保留原查询、时间、发布版本与校验引用。示例不写假的 SHA-256；以后若装入隔离测试，由原发布链生成校验值。时间统一用 `2026-11-06T08:00:00Z`，解析版本为 `amazon-v1`。

| 查询 | 搜索返回及原件别名 | 原件中可观察的事实 |
| --- | --- | --- |
| Q1 `under sink organizer` | A（`AMZ-A@v3`）、B（`AMZ-B@v1`） | A 展示价 USD 29.99，免打孔、可调宽 38–55 cm、带避管空间、单件装。B 展示价 USD 24.99，固定宽 42 cm、需打孔、单件装。 |
| Q2 `under sink mat` | C（`AMZ-C@v1`）、D（`AMZ-D@v1`） | C 展示价 USD 15.99，带边硅胶防漏垫。D 展示价 USD 21.99，带边可裁剪防漏垫。 |
| Q3 `under sink organizer for shallow cabinets` | E（`AMZ-E@v1`） | 有标题和主图，价格、币种、尺寸、安装方式和可售状态未知。 |

可用 `mode=category, categoryNode=900107001` 的合成查询替换 Q1 做类目入口对照，映射到同一组合成详情；节点只供离线样例使用。原件规格来自合成商品描述或属性，价格采用同一展示报价口径；均无评分、评价数、真实销量或时间序列。

| 供货样例 | 内容 |
| --- | --- |
| 已收藏 1688 条目 S1 | 同一成员可读的服务端合成发布 `SOURCING-S1@v2`，来源 SKU `sku-adjustable-white-01`，白色、可调宽 40–55 cm、免打孔、带避管空间、单件装。人工选择该 SKU，计划采购 **20 件**。和 A 的差异是最小宽度从 38 cm 变为 40 cm，记录理由「接受 40 cm 起，暂不覆盖更窄柜体」。 |

### 正常走查 · W1

1. 用 Q1 查得 A/B。机会说明填写「给希望免打孔且要绕开水管的用户，验证可调宽、单件装的收纳架」。依据是 A/B 的可观察差异和样本展示价 USD 24.99–29.99。标为小样本待验证方向，需求规模和销量未知。
2. 卖家确认这个方向，以 A 为代表候选；打开同一项目的选品页。按要求匹配 S1，选择 `sku-adjustable-white-01` 和 **20 件**，保留上述尺寸差异和理由。回读核对记录仍指向 A v3 与 S1 v2。
3. 试算采用 **每单一件**、假设售价 USD 30.00、商家直发、全额退款概率 5%。采用 QP1，人工汇率 USD 0.200000/CNY，仅为合成输入；采购包装成本折合 USD 8.00/件。以下输入同用 2026-11-06 的样例依据，售价/退款率/物流及费率由样例假设表提供，采购和汇率各注明自己的出处。

   | 金额口径 | 正常成交 95% | 全额退款 5% |
   | --- | ---: | ---: |
   | 净收入 | USD 30.00 | USD 0.00 |
   | 采购包装实际消耗 | USD 8.00 | USD 8.00（无回收） |
   | 物流/履约 | USD 6.00 | USD 8.00（含退运） |
   | 平台费 | 售价的 10%，固定费 0 | 比例与固定费均明确为 0 |
   | 广告 | USD 3.00 | USD 3.00 |
   | 卖家税及额外汇兑费用 | 样例不适用 | 样例不适用 |

   预期 `COMPUTABLE`。正常贡献 USD 10.00，退款贡献 −USD 19.00，期望贡献 **USD 8.55/次销售尝试**，参考保本售价 **USD 20.00**。采购 20 件用于判断报价档位，单件试算仍按每单一件计算。
4. 卖家填写「按合成报价可做小量测试，接受尺寸差异」并只批准 A。B 与 S1 不进入转入子集。合成转入回执预期包含一条来源 `AMZ-A@v3` 的商品准备条目。离线按合同核对该预期；现场需用 Preparation 原回执确认。

## 现有能力与最小缺口

| 环节 | 可直接沿用的能力 | 首试需要补齐或确认 |
| --- | --- | --- |
| 关键词/类目与证据 | [查询及发现合同](../architecture/market-research-selection.md)已有 `keyword` / `category` 发现和详情，原 Data Services 保存证据，Research 按授权引用回读。同站点同 ASIN 的重复观察沿现有归组。 | 把当前查询及实际结果范围带入机会判断，明确切换查询只切换本次证据范围。当前解析器明确缺评分、评价数和完整变体，也没有真实销量或趋势；本试点用可验证的页面规格和展示价形成机会假设。 |
| 机会与人工交接 | [现有产品分工](../product/market-research-selection-centers-v1.md)有项目、候选、样本读取及同项目交接；`product.research.agent` 处理已选资料。 | 缺从查询样本形成「机会、要求、证据、未知项」以及让人确认后带到选品的完整业务路径。先定同项目里的最小输入输出和确认方式；如新增持久化事实、状态或智能体执行，需独立设计并达到 `IMPLEMENTATION_READY`。 |
| 1688 匹配和核对 | [货源核对合同](../architecture/research-supplier-review-v1.md)已有对获准、已收藏 1688 原版的选择，保存准确 SKU、正整数件数、差异和理由。运行须启用对应能力、预置 schema 和原件读权限。 | 首试用有限已收藏货源验证按要求人工匹配。按关键词自动找货仍缺获准来源及搜索接线；万邦的固定版本、指定 SKU/数量报价、MOQ 与混批补证继续独立推进。 |
| 试算和准备 | [参考试算](../architecture/research-manual-cost-preview-v1.md)已有人工输入、缺项提示及每单一件计算；[原转入合同](../architecture/market-research-selection.md#5-用户路径与跨-owner-一致性)已有人工决定、准确商品子集与原回执。 | 首试确认同一候选的货源核对、试算输入、批准和原件回执能串起来。若要求商品准备以 1688 SKU 为主原件，或随转入保存报价及试算快照，需另定 Preparation 交接范围及设计准入。 |

实际取数前，需对目标环境与操作者核实站点适用许可（自动访问及后续保留、分析和展示）、原件和项目权限、站点配置与执行窗口、查询范围和计费上限。优先复用该关键词/类目已有的可读原件与查询记录。先前指定 ASIN 的单次范围与预算不直接套用到新查询。1688 自动报价或其他来源按自己的准入证据判断。
