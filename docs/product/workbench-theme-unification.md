# 工作台统一主题（2026-10-17 用户决定）

用户要求统一全部主题，避免每个页面形成独立外观。执行 [#769](https://github.com/qq550723504/task-processor/issues/769)，覆盖工作台全部十个模块、共享控件和弹窗浮层。

## 共同视觉依据

沿用 [Figma Product Authority](final-ui-ia-authority.md) 与原工作台的明暗配色、品牌和组件语言；本轮已实时读取技能库公共工作台浅色6734:1666、深色6734:1427的高保真上下文和截图。当前Console已具备更易读的辅助文字与主操作配色，作为现有唯一语义主题源继续复用。

用户本轮决定替代历史页面各自覆盖背景、表面、文字、主色、字号和普通控件外观的实现。页面原Figma的职责、信息架构、实际交互和可用能力边界保持，不把目录、表格、编辑器或工作流改成同一布局，不复制原图示例数据或素材为业务事实。

## 视觉 owner 与消费

`src/app/console.css`统一拥有工作台的明暗语义变量、文字层级、页边距/间距、圆角与控件尺度；现有next-themes继续拥有主题选择和持久偏好。各页面只消费语义变量，保留局部业务布局，不重新定义通用主题变量或独立色板。

- 主操作使用primary/primary-foreground，信息强调使用info/console-blue，紫色与粉色仅用于现有有意义的内容分类；成功、警告、错误使用对应状态语义。
- 页面标题28px、章节18px、卡片标题16px、弹窗标题20px、正文13px、辅助12px；原业务指标、代码和正文内容可使用符合职责的独立尺度。
- 页边距28px（窄屏16px），章节间距20px；普通卡片圆角12px，控件40px/紧凑32px、圆角10px。业务专用布局与必要触达区域保留。
- 公共Card/Button/Input/Table和原Radix/原生弹窗继续复用；挂到body的浮层也应消费同一工作台主题，不能退回根页默认灰黑主题。
- 图表序列、平台/品牌原资产、商品原图、编辑器用户已保存的文字/高亮颜色属于内容表达，不改写为主题色。富文本编辑器外框和工具栏跟随公共主题。

## 深层页面与异常状态

ApplicationFrame现有的外层主题作用域已覆盖工作台加载、企业访问跳转与访问受阻页面，不在早返回分支重复挂载主题；身份检查、恢复入口与重试行为仍由原有组件负责。

新建、管理、通知未开放和官方授权返回页面的标题沿用页面标题尺度。原生弹窗及抽屉主标题使用弹窗标题尺度，内部章节和卡片标题继续区分层级。弹窗表面使用card/popover，遮罩使用overlay，阴影使用shadow-color；项目卡片与弹窗不得把页面背景当作卡片表面。保留抽屉的贴边布局和业务表单宽度。

账户菜单的资料入口使用普通文字及主色悬停，退出入口沿用原危险色；主题开关也消费主色。只改变表示，不改变导航、登录状态、保存、启停或配置事实。
