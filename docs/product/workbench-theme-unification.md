## 共同视觉依据

当前视觉 Authority 为用户确认的 [SUMI Design System 1.0｜统一规范 V1.3](https://www.figma.com/design/tg48P46SSXl6TBy9lZwg63?node-id=10690-1069)。六张样板：我的店铺 Light/Dark `10957:908 / 10957:1447`、店铺矩阵 `10957:1098 / 10957:1629`、账户资料 `10957:1294 / 10957:1817`。本决定替代旧色板和字号；[原 Figma Product Authority](final-ui-ia-authority.md) 的路由归属、业务职责和能力合同继续适用。

用户本轮决定替代历史页面各自覆盖背景、表面、文字、主色、字号和普通控件外观的实现。页面原Figma的职责、信息架构、实际交互和可用能力边界保持，不把目录、表格、编辑器或工作流改成同一布局，不复制原图示例数据或素材为业务事实。

## 视觉 owner 与消费

`src/app/console.css`统一拥有工作台的明暗语义变量、文字层级、页边距/间距、圆角与控件尺度；现有next-themes继续拥有主题选择和持久偏好。各页面只消费语义变量，保留局部业务布局，不重新定义通用主题变量或独立色板。

- 主色浅色 `#087F6C`、深色 `#42D2B0`；主操作使用primary/primary-foreground，信息强调使用info/console-blue，紫色与粉色仅用于现有有意义的内容分类；成功、警告、错误使用对应状态语义。
- 页面标题24px、章节20px、卡片标题16px、弹窗标题20px、正文/表格14px、辅助至少13px；原业务指标、代码和正文内容可使用符合职责的独立尺度。
- 页边距24px（窄屏16px），章节间距20px；普通卡片圆角12px，控件40px/紧凑32px、圆角10px。业务专用布局与必要触达区域保留。
- 公共Card/Button/Input/Table和原Radix/原生弹窗继续复用；挂到body的浮层也应消费同一工作台主题，不能退回根页默认灰黑主题。
- 图表序列、平台/品牌原资产、商品原图、编辑器用户已保存的文字/高亮颜色属于内容表达，不改写为主题色。富文本编辑器外框和工具栏跟随公共主题。

## 深层页面与异常状态

ApplicationFrame现有的外层主题作用域已覆盖工作台加载、企业访问跳转与访问受阻页面，不在早返回分支重复挂载主题；身份检查、恢复入口与重试行为仍由原有组件负责。

新建、管理、通知未开放和官方授权返回页面的标题沿用页面标题尺度。原生弹窗及抽屉主标题使用弹窗标题尺度，内部章节和卡片标题继续区分层级。弹窗表面使用card/popover，遮罩使用overlay，阴影使用shadow-color；项目卡片与弹窗不得把页面背景当作卡片表面。保留抽屉的贴边布局和业务表单宽度。

账户菜单的资料入口使用普通文字及主色悬停，退出入口沿用原危险色；主题开关也消费主色。只改变表示，不改变导航、登录状态、保存、启停或配置事实。

工作台默认边框在CSS基础层消费border变量，避免Tailwind未指定颜色的border使用当前文字色。显式状态工具类和组件局部边框继续优先，不以全局高优先级覆盖警告、错误、选中或用户正文样式。

## 工程与事实边界

Design Basis: Reuse Existing Architecture。开工准入与完整引用已先于实现写入 #769。沿既有 Console、CSS Modules、Tailwind、共享组件与 next-themes 边界；Store Center、Operations Cockpit、Account Facts 的原 owner、读取合同与编辑入口保持。

桌面侧栏在同一导航树上收窄为图标栏；展开按钮常驻侧栏顶部，图标仍有可访问名称和原导航目标。收窄偏好只在当前 shell 内存中保存，不新增持久化。账户资料摘要通过原 settings/business/verification 路由进入编辑；账户编号与登录信息可展开查看。店铺保留原筛选、分组、负责人、同步和接入条件；矩阵仍显示当前人工经营事实，不为匹配样板增加示例指标或接口。

不改变菜单/路由、API调用、权限、启停、模板/默认/版本、CAS/幂等/UNKNOWN、持久化或恢复协议，不迁移数据或新增provider调用。当前偏好storage key、用户选定主题、企业上下文及浏览器业务会话继续保留。

实现和隔离视觉/回归证据写Issue/PR；合并、现有运行实例更新与用户产品验收分别记录，未执行时保持NOT_RUN。
