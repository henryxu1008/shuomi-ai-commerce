# 候选资料带入 SHEIN 平台草稿

Product Decision: PD-COMPLETION-SHEIN-IMPORT-2026-10-16

用户批准：先明确候选版本固定、属性与 SKU 映射、覆盖范围、权限和并发合同，再做 SHEIN 平台草稿的带入预览与确认；独立页面，保留返回草稿、商品、批次上下文，复用 CompletionDraft 与 Target 保存，不自动发布。

## 本轮结果

操作人从待补全草稿进入独立的“SHEIN 带入预览”页，选择当前可访问的 SHEIN 店铺及其**已保存的平台草稿**。平台分类、SKU 和批准图片沿用该草稿；没有已保存 Target 时明确引导先在现有供应链接口准备并保存。此页不建设第二套平台编辑器。

固定候选 Rn、SourceItem Vn、目标记录 Rm。页面展示来源 SKU 编码与销售规格和目标 SKC/SKU，用户明确配对；不按名称、空编码或相同编码推断。选择属性目标、枚举值、价格和库存仓库后，先预览本次覆盖的完整前后值，再明确确认，追加 Target Rm+1。确认只保存本地平台草稿。

## 取值与覆盖

- 标题、描述分别选择，替换英文项，其他语言保留。空文字可以明确选择；不默认清空。
- 通用候选属性只映射当前规则中可见、启用、SPU 层的普通/成分属性。每个来源属性对应一个目标属性和一个已有枚举值，或规则允许的整数/附加输入值；附加值来自该候选值，不伪造新值。完整多选/成分组合编辑继续使用既有平台编辑器；现有校验问题如实保留。
- 每个来源 SKU 最多映射一个目标 SKU，每个目标最多接收一个来源。只改变明确选择的价格/库存，不增删/排序 SKU，不改供应商 SKU、销售规格、尺码或包装。
- 自营价格只带入 USD 零售价；半托管/全托管带入当前规则币种的供货价，不换算、不舍入。未填不可选择，0 保留为明确的零，原校验可继续指出不可发布。
- 库存须在 0..99999；非全托管按可用美国仓明确选择，替换该仓一项并保留其他仓；无仓规则或全托管明确选择无仓总库存，不拆分数量。
- 未映射、未选择和未填写的值保留目标原值；页面逐项说明跳过。分类、品牌、图片/批准、其他属性/语言/仓库、包装等保持原样。

## 权限、界面与限制

沿当前 supply.read/manage、本人及企业成员范围、Store 当前官方授权、SourceSelector 和原 Target CAS/幂等合同。预览需要管理权限；只读用户可查看候选资料但不能预览或确认写入。没有配置/授权/规则时显示实际不可用，不提供假店铺、假规则或成功。

UI authority 继承 [当前 UI/IA](final-ui-ia-authority.md)、Figma `tg48P46SSXl6TBy9lZwg63` / `31:463`、待补全 `2667:1948`、待适配 `3507:1965` / `3507:3143`；独立页面是本次用户决定，不声称存在新 frame。复用 Console、主题、表格及命令恢复组件，不增加顶级菜单或模态框。

不做真实 SHEIN mutation、自动发布、模型调用、批量带入、跨平台泛化、平台 SKU 结构编辑、新表/迁移/第二事实源、试用实例更新。既有文字历史恢复仍只恢复标题和描述，保留当前结构化候选。

设计及准入见 [独立增量架构](../architecture/completion-shein-import-v1.md)。本决定仅对 SHEIN 取代此前“Target 仅带入文字”的阶段限制，TikTok/TEMU 及 CompletionDraft 原合同保持原范围。
