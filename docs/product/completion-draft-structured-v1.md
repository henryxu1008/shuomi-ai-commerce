# 待补全草稿的结构化候选资料

Product Decision: PD-COMPLETION-STRUCTURED-2026-10-15 / Issue #718

2026-10-15 用户批准：先明确结构化保存、权限、并发和历史比较/恢复合同，再在独立页面编辑候选商品属性、现有 SKU 的价格和库存。固定来源版本，保留返回草稿、商品和批次上下文，复用 CompletionDraft 与版本保存。

用户随后明确选择：**历史恢复暂时仍只采用旧版标题/描述，保留当前候选属性、价格、库存；新增字段进入历史详情和差异比较。**

## 结果与范围

有供应链管理权限的操作人可从草稿进入“编辑商品属性和 SKU”，在固定 Vn 的现有变体上准备候选价格、币种和库存，以及独立的通用商品属性。保存追加不可变 Rn，刷新或重新进入继续编辑。

- 原商品、固定来源、SKU 编码/销售规格/图片不改变，不增删 SKU。
- 候选资料不代表平台定价、实际库存、资产批准、适配或发布。未填和数值 0 分开。
- 标题编辑和文字恢复保留当前结构化内容；尚未保存过结构化内容的版本明确显示未保存，不把来源原值伪装成历史候选。编辑页来源预填在保存前明确为未保存候选。
- 不做平台映射、店铺、模型/provider、worker、迁移/backfill 或第二事实源。保留实例更新和真实数据操作另授权。
