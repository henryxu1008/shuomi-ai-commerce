# 未绑定店铺的待补全草稿

Product Decision: PD-SUPPLY-UNBOUND-COMPLETION-2026-10-12

## 用户决定与本轮结果

2026-10-12，用户明确选择：**允许保存未绑定店铺的真实待补全草稿；以后配置店铺后再适配、校验和上传。**

这替代 #605 在当前无配置阶段“草稿必须绑定店铺、不能交付本地草稿”的限制。既有正式 SHEIN 上传目标和授权不变量仍保留；阶段性交付不能写成平台上传或用户验收 PASS。

使用者是已有商品来源与供应链管理权限的企业操作人。当前场景是在 SHEIN 配置尚未准备时，先为已转入待适配的商品整理候选标题和描述，保存后刷新或重新登录继续编辑。

本轮交付：从“待适配”选择商品进入“待补全”，编辑并保存候选标题/描述；列表和编辑器显示真实保存版本及原始资料。原始图片、规格、价格等来源资料可查看，仍属于原 owner。平台类目、品牌编码、规格、定价与库存等平台字段须在配置真实店铺、读取当前规则后完成。

## 事实与限制

- Catalog 的原始商品及来源版本不变；Listing 保存的是用户准备发布的候选内容，不声称候选内容已经成为来源商品事实。
- 未绑定草稿始终是“待补全 / 未绑定店铺 / 尚未平台校验”。保存不表示已适配、已审核、已上传，也不产生批准或模型回执。
- 后续选择真实店铺时可明确带入已保存草稿的标题/描述，走原店铺规则、补全、资产批准和 TargetRecord 校验路径。新平台资料和上传依然按当前授权及原版本合同生成，不能覆写历史渠道记录。
- 本轮不调用模型、支付或 SHEIN，不新增通用草稿平台、任务/工作流、商品同步、legacy 包装、旧数据迁移或第二来源事实。真实环境 schema/grant/部署操作仍须有具体授权。
