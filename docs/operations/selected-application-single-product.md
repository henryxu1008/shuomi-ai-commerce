# 单件自有商品优选申请

入口：正常登录并选择企业后，进入“供应市场 → 优选申请 → 发起申请”，路径为 `/workbench/supply/applications/new`。

1. 在“选择申请商品”按关键词查找本人自有商品。未优化或资料不完整的商品正常显示为“不可申请”，只有已有真实智能优化结果且符合申请条件的商品可以选择；每次选择一件。
2. 点击“下一步：填写供货信息”，填写库存或生产能力、起订量、发货时效、省市及价格说明。
3. 填写售后政策，保存必要的私密资质附件，确认自有商品及披露声明，再“提交申请”。
4. 从保存回执打开申请详情，或从“申请进度 / 申请记录”查看人工评估及补充要求。提交不会自动批准或发布到硕米优选。

发货省份和城市使用联动下拉：先选省，再选该省下的城市；切换省份会清空城市，
不会默认代选。直辖市使用同名城市，省直管地区显示真实地区名称。此交互与自营
供货草稿共用组件，提交的 `province` / `city` 仍为中文名称，不改变已有地址记录。
省市名称来自固定版本 [@vant/area-data 2.2.0](https://www.npmjs.com/package/@vant/area-data/v/2.2.0)
的离线数据（MIT 许可），复用已有 Select；不引入 Vant UI 或第三方地址请求。

没有自有商品时，可从空状态进入“添加自有商品”。商品须完成当前智能优化与实际 Apply 后才可申请；只有手工保存资料不构成优化证据。1688 采集、市场选入、SDS 模板或成品等来源不属于可申请的自有商品。筛选与分页使用现有自有商品读取；每页最多核对 20 件，列表明确展示本页可申请数量，不把自有商品总数当作全库可申请数量。某页没有合格商品仍可继续下一页。无图片等未达条件的商品不会使资格查询或概览整体报错；权限、版本或依赖读取失败仍提示重试，并阻止使用旧资格。

“返回选择商品”保留尚未提交的供货字段和已保存附件，换选商品后须重新确认披露声明。刷新或离开页面不保存未提交表单；已发送的单件命令与附件未知结果仍沿用原操作记录和原幂等键恢复，不以新申请替代。企业切换清除当前表单和选择，原权限与服务端来源/版本核验保持不变。

本轮用户于 2026-10-15 明确保留单件申请。选择和供货页面依据 Figma `997:764` / `1004:892` 的布局，使用单选而非原型多选；没有对应当前合同的 ERP/插件来源、自定义分类和申请状态过滤器不伪装成可用。库存、产能、周期与省市沿用现有真实字段。后续批量申请不在本轮范围。

申请与文件继续由现有 Product SupplyMarket/Collection/Catalog/Apply、私密附件存储保存，没有新增持久化 owner。开发自检、页面 fixture 预览与 CI 不代表真实用户验收；共享实例更新、真实资质上传、真实申请提交及平台发布均未执行。
