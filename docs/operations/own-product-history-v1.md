# 查看自有商品保存历史

当前阶段依据：[历史读取和权限合同](../architecture/own-product-history-v1.md)。实现和试用不代表合并或生产验收。

正常登录并选择当前企业，在“数据服务 → 我的数据 → 自有商品库”打开商品详情，点击“版本历史”。列表按手工保存版本倒序展示真实保存时间和商品名称。每页最多20个版本，“查看更早版本”读取下一页；“刷新最新历史”回到最新保存记录。

点击“查看版本”打开独立旧版详情，查看当时的商品属性、图片及各SKU资料。页面明确显示版本号和当次保存时间；历史资料只读，“查看当前资料”返回当前商品详情。

勾选两个保存版本并点击“对比所选版本”，进入独立对比页。比较起点/终点、保存时间和名称明确展示；商品属性、图片顺序和SKU资料的新增/删除/修改逐项显示。SKU按原稳定身份匹配，修改SKU编码不会被当成删除后新增，显式零价格/零库存保留。

版本号可能跳号：AI衍生快照使用同一Catalog序列，但不属于手工保存历史。每次手工保存追加新版本；旧快照及已创建草稿的固定引用保持。

访问需要当前企业的 `workbench.collection.read` 和原操作人自己的商品；无须编辑权限。切换企业或身份会重新读取。权限被撤销、商品或所在分组已归档时历史入口不能继续读取；读取失败可显式重试。

当前不开放回滚、编辑旧版本或自动更新已有草稿。价格/库存仍为保存当时的来源声明，没有实时库存同步或自动平台发布。

路径：

- 当前商品：`/workbench/data/mine/own/<itemId>`
- 保存历史：`/workbench/data/mine/own/<itemId>/history`
- 旧版详情：`/workbench/data/mine/own/<itemId>/history/<version>`
- 版本对比：`/workbench/data/mine/own/<itemId>/history/compare?from=<version>&to=<version>`

启停沿原实例交接的保留数据命令；本能力不需要初始化、迁移或清理数据库，也不产生新对象上传或容量占用。
