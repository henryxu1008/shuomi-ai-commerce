# SHEIN Workspace Rules

Owns the current pure SHEIN review, readiness, taxonomy and template-freshness
rules in this package. Local draft values and strict codecs belong to
`../offlinepackage`; assembly belongs to `../draft`, and platform execution
belongs to its current Listing / Marketplace owner.

The old ListingKit orchestration and compatibility DTO owner is retired; do not
recreate it from earlier workspace examples. See the
[confirmed draft boundary](../../../../docs/architecture/legacy-shein-draft-assembly-closure-retirement-boundary.md).
